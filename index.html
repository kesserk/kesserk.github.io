Projects

T2D Risk Predictor

In progress

A public pipeline for fairness-aware Type-2 diabetes risk prediction, written alongside the Portsmouth PhD. It uses the NHANES open dataset, not the NHS data from the doctorate.

In the repository today: a FastAPI skeleton, Docker, GitHub Actions, an NHANES exploratory notebook and a baseline model notebook. Still ahead, and not claimed as finished: comparison of logistic regression, XGBoost, an MLP and a tabular transformer; Fairlearn subgroup audits; SHAP explanations; and any published scores. The README states that no performance numbers are reported yet.

github.com/kesserk/t2d-risk-predictor
